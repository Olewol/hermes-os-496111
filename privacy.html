2. Hva denne siden er

Dette er en statisk Github Pages-side som kun tjener som OAuth-branding-side for Google Cloud-prosjektet hermes-os-496111. Siden inneholder ingen funksjonalitet for innlogging, skjema, analytics, cookies eller tredjepartsscripts.

3. Personopplysninger vi behandler

Ingen. Siden setter ingen cookies, lagrer ingen IP-adresser, bruker ingen analyseverktøy (ingen Google Analytics, Matomo, Plausible, osv.), og laster inn ingen eksterne ressurser (ingen CDN, fonts, scripts, iframes). Serverloggar hos GitHub Pages kan inneholde standard HTTP-loggar (IP, tid, forespurt URL, user-agent) — disse kontrolleres av GitHub, ikke av oss.

4. Formål og rettslig grunnlag

Eneste formål: oppfylle Googles krav til homepage URL og privacy policy URL for å publisere OAuth-skjerm til produksjon. Rettslig grunnlag: art. 6.1(b) GDPR (avtale med Google om OAuth-tjeneste).

5. Overføring til tredjeland

GitHub Pages hostes av GitHub Inc. (USA). GitHubs egne personvernerklæring gjelder for serverloggar. Vi overfører ingen data aktivt.

6. Oppbevaring

Ingen personopplysninger oppbevares av oss. GitHubs loggoppbevaring styrer av GitHub.

7. Dine rettigheter

Siden vi ikke behandler personopplysninger, er det ingen data å få tilgang til, rette, slette eller beperke. Du kan kontakte GitHub for data de behandler.

8. Endringer

Dato for siste oppdatering vises øverst. Vesentlige endringer vil kreve ny versjon med ny dato.
